# Codex Guide

1. Generate Codex plugin files:

```bash
ffm plugin scaffold --target codex --out .ffm-plugins
```

2. Apply `.ffm-plugins/codex/mcp.json` to Codex MCP config.
3. Add `.ffm-plugins/codex/AGENTS.md` guidance in your workspace.
4. Add `.ffm-plugins/codex/skill-free-fast.md` as a skill prompt or operating note.
